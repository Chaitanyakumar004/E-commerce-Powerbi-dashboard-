# E-commerce-Powerbi-dashboard-
# 🛒 E-Commerce Sales Analytics Dashboard | Power BI

An interactive **E-Commerce Sales Analytics Dashboard** built using **Microsoft Power BI** to analyze sales performance, customer behavior, profitability, geographical performance, and order trends.

The project is based on an e-commerce dataset containing **150K+ transactions** covering multiple business dimensions such as customers, orders, sales channels, payments, shipping, marketing, returns, loyalty, and profitability.

---

## 📊 Project Overview

This Power BI project transforms raw e-commerce transaction data into an interactive business intelligence dashboard.

The dashboard helps answer questions such as:

* How are sales and profits performing?
* Which regions generate the most revenue?
* Which countries and states contribute the most sales?
* How do different sales channels perform?
* What is the relationship between sales quantity, revenue, and profit?
* Which customers and segments are most valuable?
* How are delivery and returns performing?
* What impact do discounts, marketing channels, and loyalty programs have?

---

The main objectives of this project are:

## 📈 Dashboard Features

### 1. Sales & Profit Analysis

The dashboard compares:

* Gross Sales
* Net Sales
* Profit
* Quantity
* Profitability by sales channel

A scatter chart is used to analyze the relationship between **Net Sales and Profit**, with sales channels and quantity providing additional context.

---

### 2. Regional Performance

Sales and profit are analyzed across different geographical regions.

The dashboard provides:

* Gross Sales by Region
* Profit by Region
* Regional comparison
* Interactive Region filtering

---

### 3. Geographic Analysis

A map-based visualization is used to analyze performance across customer states.

Key metrics include:

* Net Sales
* Profit
* Customer State
* Region

This helps identify geographical areas contributing significantly to business performance.

---

### 4. Country-Level Sales

A country-based visualization shows the distribution of **Net Sales across customer countries**.

This enables analysis of:

* International sales distribution
* Country-level revenue contribution
* Geographic customer concentration

---

### 5. Customer Analytics

The dataset supports detailed customer analysis using:

* Customer Age
* Gender
* Customer Segment
* Customer Type
* Customer Lifetime Value
* Repeat Customer Status
* Customer Order Count
* Customer Rating
* Review Sentiment

These fields can be used to understand customer behavior and identify valuable customer groups.

---

### 6. Marketing & Loyalty Analytics

Marketing performance can be analyzed using:

* Marketing Channel
* Campaign Name
* Coupon Code
* Loyalty Points Earned
* Loyalty Points Redeemed
* Customer Lifetime Value
* Repeat Customer Status

This provides insights into customer engagement and marketing effectiveness.

---

### 7. Delivery & Returns Analysis

Operational performance can be explored using:

* Delivery Days
* Estimated Delivery Days
* Delivery Status
* Shipping Method
* Return Status
* Return Reason

This helps identify potential delivery and return-related issues.

Clone this repository:


Open:


If Power BI asks for data-source parameters or credentials, provide the required source information.

Use the available visualizations and **Region** filter to interact with the report.
